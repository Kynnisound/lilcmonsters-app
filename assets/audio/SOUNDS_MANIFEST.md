# SOUNDS_MANIFEST — Lil C Monsters (SeaMonsters), phase 1

Generated 2026-10-27. Every sound comes in two formats with the same name: `.ogg` (Ogg Vorbis) and `.m4a` (AAC-LC, 96 kb/s mono / 128 kb/s stereo). Both are 44.1 kHz; SFX mono, ambience loops stereo. Loops normalised to about −16 LUFS integrated; SFX loudness-matched (RMS-based) with true peak ≤ −2 dBFS (all measured ≤ −2.4 dBTP after encoding). Leading/trailing silence trimmed, short fades added to avoid clicks.

**Licence summary:** every file below is CC0 1.0 or public domain. Commercial use in the app is allowed, attribution is not required, and there are no share-alike or non-commercial terms. Sources used: Kenney.nl (CC0 packs), OpenGameArt.org (CC0-only entries), Wikimedia Commons (CC0 / PD). No account, login or payment was used. Freesound and Pixabay were not used because they block non-browser access and Freesound originals need a login.

Credit is optional, but we can add a line such as "Sounds: Kenney.nl, OpenGameArt contributors (rubberduck, Peludo, Thimras), Wikimedia Commons (Jarrod stanley, avphillips)" to the credits screen.

## Notes for integration

- **iOS:** the iOS player that audioplayers uses (AVPlayer) cannot play Ogg Vorbis. Use the `.m4a` files on iOS, or on both platforms for simplicity. The `.ogg` files work on Android and web. The table lists the `.ogg` name; each `.m4a` twin has the same source, licence and duration (±5 ms).

- Asset folder `assets/audio/` is **not yet declared in pubspec.yaml** (only `assets/sounds/` is). Webboy needs to add `- assets/audio/beach/`, `- assets/audio/map/`, `- assets/audio/ui/`, `- assets/audio/puzzle/`, `- assets/audio/shadow/`, `- assets/audio/common/`. I did not edit pubspec or the Dart code.
- Loops are cut on an equal-power crossfade, so the last sample flows into the first. Play them with `ReleaseMode.loop`. Some Android/iOS players add a tiny gap when looping compressed files. If that's audible, use `.m4a` or a gapless player (e.g. just_audio `LoopingAudioSource`).
- Suggested in-app volume: ambience about 0.5–0.6, SFX 0.8–1.0.
- `beach_shell.ogg` is a stand-in (a light glass tap from Kenney), not a recording of a real shell.
- Original source files and the build script (`build.py`) are kept on the build box at `/workspace/audio_src/` to allow re-cuts.
- Kenney licence text (in every pack's License.txt): "License: (Creative Commons Zero, CC0) http://creativecommons.org/publicdomain/zero/1.0/ — This content is free to use in personal, educational and commercial projects."
